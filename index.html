01

Cross-platform firstMultiplataforma desde el inicio

Shared business logic and UI with Kotlin and Compose Multiplatform, dropping to native code only where it matters. Lógica de negocio e interfaz compartidas con Kotlin y Compose Multiplatform, con código nativo solo donde aporta.

No accounts required, data kept on the device by default, and clear consent for anything that leaves it. Sin cuentas obligatorias, los datos se quedan en el dispositivo por defecto, y consentimiento claro para todo lo que salga de él.

03

Built to lastHecho para durar

Clean Architecture, clear module boundaries and careful releases, so products keep improving instead of breaking. Clean Architecture, límites claros entre módulos y publicaciones cuidadosas, para que los productos mejoren en lugar de romperse.
